# Music Playlist Manager

**DSA Case Study using Doubly Linked List in C++**

## Aim
To implement a menu-driven Music Playlist Manager using a Doubly Linked List.

## Features
- Add a song to the playlist
- Delete a song
- Display the playlist in forward and reverse order
- Play the current song
- Navigate to the next and previous songs
- Play the complete playlist
- Repeat the playlist a specified number of times
- Display the current song

## Data Structure
A Doubly Linked List is used to store song titles and artist names. Each node contains `prev` and `next` pointers to support navigation in both directions.

## Technologies Used
- C++
- Visual Studio Code
- GitHub

## How to Run
1. Download the C++ source file from this repository.
2. Open it in Visual Studio Code.
3. Compile the program using a C++ compiler.
4. Run the executable and follow the menu options.

## Project Files
- `DSA Music Playlist Code.cpp` : C++ source code
- `DSA Music Playlist Output.docx` : Program output and case study documentation

## Conclusion
This project demonstrates the implementation of a Doubly Linked List and its use in song insertion, deletion, traversal, and bidirectional navigation.
